# totally-real-wordle

a discord user application that lets you share any wordle score you want.

## usage

1. [click here](https://discord.com/oauth2/authorize?client_id=1516974336810942544&integration_type=1&scope=applications.commands) to install the user application
2. run the `/share` command and populate the modal
    - note: discord modals don't have an emoji picker, so i recommend using the discord text box to make the grid, and then cut it and paste it in the field in the modal
    - p.s.: the wordle bot uses these emojis: ⬛🟨🟩

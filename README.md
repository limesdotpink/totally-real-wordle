# totally real wordle

a discord user application that lets you share any wordle score you want.

<img width="1280" height="640" alt="wordle" src="https://github.com/user-attachments/assets/2f7a2b66-4028-4066-b37b-ef1a775fea69" />

## usage

1. <a href="https://discord.com/oauth2/authorize?client_id=1516974336810942544&integration_type=1&scope=applications.commands" target="_blank">click here</a> to install the user application
2. run the `/share` command and populate the modal
    - note: discord modals don't have an emoji picker, so i recommend using the discord text box to make the grid, and then cut it and paste it in the field in the modal
    - p.s.: the wordle bot uses these emojis: ⬛🟨🟩
